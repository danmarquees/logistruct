# 📚 LogiStruct - Documentação

Bem-vindo ao diretório de documentação do **LogiStruct**. Este espaço é dedicado a centralizar as informações técnicas sobre as funcionalidades implementadas e propostas de melhorias futuras.

## 📂 Estrutura do Diretório

- `/features`: Documentação detalhada da implementação de cada função ou módulo necessário (ex: Cálculo Tributário, Gestão de Estoque).
- `/improvements`: Registro e planejamento de futuras melhorias, otimizações e novas funcionalidades.

## ✍️ Como Contribuir

Para documentar uma nova funcionalidade, copie o arquivo `features/TEMPLATE.md`, renomeie para o nome da funcionalidade e preencha as seções adequadamente.
Para registrar uma nova melhoria, utilize o arquivo `improvements/TEMPLATE.md`.
